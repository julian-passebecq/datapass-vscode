## 5. Decisions
- A cell is drawn by the existing panel renderers under the id `dash:<screen>:<panel>`, so there is no new host message and no new renderer. Its state lives in `layout.dash`, not in panel params (those are capped at 16).
- Params apply in this order: panel, then metric, then the target's `?query`, then edits made in the dashboard. Switching the metric drops edits of the keys that metric sets.
- `coming` is set only for packages not merged yet (STOR1, CLEAN1, RATIO1, VIS3DQ, RUNX1 with a fallback).
- A dashboard Sankey with no path uses the listed graph with the most flows between groups, because FIXDBT is single-platform.
- Opening dashboards switches the workbench to tabs mode so the screen gets the full width.
