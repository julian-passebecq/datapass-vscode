# The architecture

The **Architecture** panel (bottom panel) draws the client's components, where each one lives and how they connect.

- Click a component to see its files, repository and state in **Details**.
- A component whose repository is not on this computer shows as *not cloned*, never as *missing*.
- When the project has several architecture options, the tree and the diagram follow the selected one.

In Standard mode the window opens on this panel.
