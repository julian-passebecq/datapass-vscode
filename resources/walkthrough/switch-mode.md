# Switch mode

DataPass has four modes; they change what is shown, never your files or the safety checks:

| Mode | What you see |
|---|---|
| **Vanilla** | VS Code's Explorer, DataPass's Git view and the AI exchange |
| **Standard** | Vanilla + the architecture diagram and Details (default) |
| **DataPass** | Standard + the Project tree, options, project sheet, readiness |
| **Advanced** | everything (board, Work and Galaxy views) |

Switch with **DataPass: Switch Mode** or the mode in the status bar.
